# Intake Questions

Ask the user these before any code. Don't ask all at once — group into a few rounds.

## Round 1: Brand & product

1. **Brand name** + how it should be styled (lowercase, with dot, capitalized?)
2. **One-line product description** ("What does it do?")
3. **Target audience** in one phrase ("Indian MSME accountants", "remote dev teams", etc.)
4. **Tagline** (3-6 words, all-caps treatment)

## Round 2: Visual identity

5. **Primary brand color** (hex)
6. **Secondary accent** or "build me a 3-stop gradient from your primary" — show options from `brand-tokens-quickstart.md`
7. **Font preference**: serif hero / chunky sans hero / "you decide"
8. **Tone**: warm-approachable / sleek-corporate / playful-bold / editorial-restrained

## Round 3: Video specs

9. **Length**: 15s (reel) / 20s (standard) / 30s (longer reel) / 60s (YouTube)
10. **Aspect ratios needed**: 16:9 only / 9:16 only / both / both + 1:1
11. **Music**: "I'll provide a track" / "Suggest royalty-free" / "Silent"
12. (If music): BPM if known

## Round 4: Narrative

13. **The hook**: what pain are we naming? (Try to extract a 4-6 word sentence: "Stop [verb] [noun]." works great)
14. **The payoff**: what magic moment happens? ("Books that write themselves", "Code that ships itself", etc.)
15. **The proof beat**: what visible product moment shows the magic? (Dashboard? Phone screen? Specific UI?)

## Round 5: Confirm

Show them a **storyboard table** (see `storyboard-template.md`) with proposed scenes + durations + key copy. Get sign-off before generating code.

---

## When to skip / shortcut

- User says "use my existing brand" → check if they have a brand-voice memory doc, skip to round 3
- User pastes a Figma/Notion brand guide → extract tokens automatically, skip to round 4
- User says "just make it good" → use defaults (Round 1 only) + show them the result, iterate from there
