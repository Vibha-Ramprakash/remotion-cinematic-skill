# Scene Arc Structure

The default narrative arc for cinematic product videos.

## Recommended arc (7 scenes, 20-25s total)

| # | Scene | Purpose | Duration | Template |
|---|---|---|---|---|
| 0 | Thumbnail intro | Cover frame, staggered entry, fly-to-watermark exit | 2s | `ThumbnailCard animated` |
| 1 | Hook | Name the pain. "Stop doing X." | 4s | `HookScene` |
| 2 | Brand reveal | "Meet [brand]." Glass pill → wordmark. | 2-3s | `BrandRevealScene` |
| 3 | Input sources | "From X. Or Y. From anywhere." Scattered tiles converge. | 4-6s | `InputSourcesScene` + `AnywhereCyclerScene` |
| 4 | Product demo | Dashboard with field-by-field reveal + status badge | 4-5s | `ProductDashboardScene` |
| 5 | Solution declarative | "Brand does the thing for you." | 3-4s | `SolutionScene` |
| 6 | Emotional payoff | "Magic at lightning speed." | 2-3s | `StatementScene` |
| 7 | Outro | Typewriter logo + wordmark + tagline | 3s | `OutroScene` |

## Alternative arcs

### Short (15s — Instagram Reel)
Thumbnail → Hook → Demo → Statement → Outro (skip brand reveal + input sources + solution)

### Long (60s — YouTube)
Add: testimonial scene, multi-feature demo cycle, social proof scene

### Demo-first (when product is the star)
Thumbnail → Demo → Hook → Brand → Statement → Outro
(Lead with the magic, then explain why it matters.)

## Writing each beat

| Scene | Copy formula |
|---|---|
| Hook | "Stop [bad verb] [thing]." or "[Frustration] is the worst." |
| Brand reveal | "Meet [brand]." or "Introducing [brand]." |
| Input | "From [source 1]. Or [source 2]. From [universalizer]." |
| Demo | UI text on the actual product card |
| Solution | "[Brand] [verbs] [thing] in [time/effort]." |
| Statement | "[Domain] done at [aspirational metaphor] speed." |
| Outro | Logo + tagline only |

## Pacing rules

- **Hook can be slow** — it sets the mood. 3-4s.
- **Middle scenes should accelerate** — building momentum.
- **Payoff is the apex** — give the gradient + speed-blur its moment.
- **Outro can breathe** — let the brand sit in silence for 1s.
